This notebook demonstrates how to use **SUTRA** with **Agno** (formerly PhiData), a lightweight, model-agnostic framework for building multimodal AI agents. SUTRA-V2, developed by Numeric, supports multilingual chat and instruction tasks via an OpenAI-compatible API, integrating seamlessly with Agno’s high-performance agent architecture.[](https://www.analyticsvidhya.com/blog/2025/03/agno-framework/)

## 🔧 Prerequisites

- Contact [Numeric](https://www.numeric.tech) for enterprise API access.
- Store the API key securely (e.g., in Google Colab secrets or environment variables).
- Install Agno and OpenAI SDK.

## 🔐 Step 2: Initialize SUTRA-V2 with Agno

```python
from agno.agent import Agent
import os
from agno.models.openai.like import OpenAILike


# Set SUTRA API key
api_key = os.getenv("SUTRA_API_KEY")


# Initialize the Agent with Sutra model via OpenAILike wrapper
agent = Agent(
    model=OpenAILike(
        id="sutra-v2",
        api_key=api_key,
        base_url="https://api.numeric.tech/v2"
    ),
    markdown=True,
    description="A multilingual assistant powered by SUTRA-V2",
    instructions=["Answer concisely in the requested language."],
)
```

## 💬 Step 3: Basic Chat Completion

```python
# Run the agent
response = agent.run("Explain AI in three sentences in Hindi.")
print(response.content)
```

## 🌟 Why Agno?

- **Performance**: ~10,000x faster agent creation and ~50x less memory than LangGraph, ideal for lightweight applications.[](https://www.analyticsvidhya.com/blog/2025/03/agno-framework/)
- **Flexibility**: Model-agnostic, supports multimodal tasks (text, images, etc.).
- **Ease of Use**: Minimalist API for rapid prototyping.

## 🛠 Troubleshooting

- **Invalid API Key**: Contact [Numeric](https://www.numeric.tech) for API support.
- **Model Not Found**: Use `sutra-v2`. SUTRA-V1 was deprecated on March 22, 2025.
- **Rate Limits**: Reduce request frequency or contact Numeric support.
