ఈ నోట్‌బుక్ **SUTRA-V2**ని **తెలుగు**లో ఉపయోగించడం ఎలాగో చూపిస్తుంది, ఇది బహుభాషా AI అనువర్తనాలను సృష్టించడానికి సహాయపడుతుంది. Numeric ద్వారా అభివృద్ధి చేయబడిన SUTRA-V2, తెలుగుతో సహా 50 కంటే ఎక్కువ భాషలకు మద్దతు ఇస్తుంది.

## 🔧 ముందస్తు అవసరాలు (Prerequisites)

- [Numeric](https://www.numeric.tech) నుండి SUTRA API కీని పొందండి.
- API కీని సురక్షితంగా నిల్వ చేయండి (ఉదాహరణకు, Google Colabలో రహస్య కీగా).

## 📦 దశ 1: డిపెండెన్సీలను ఇన్‌స్టాల్ చేయండి (Install Dependencies)

```bash
!pip install -qU openai
```

## 🔐 దశ 2: SUTRA క్లయింట్‌ను ప్రారంభించండి (Initialize SUTRA Client)

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_SUTRA_API_KEY",
    base_url="https://api.two.ai/v2"
)
```

## 💬 దశ 3: ప్రాథమిక చాట్ పూర్తి (Basic Chat Completion)

```python
response = client.chat.completions.create(
    model="sutra-v2",
    messages=[
        {"role": "system", "content": "మీరు సంక్షిప్తంగా సమాధానం ఇచ్చే సహాయక AI."},
        {"role": "user", "content": "కృత్రిమ మేధస్సు అంటే ఏమిటి? మూడు వాక్యాలలో వివరించండి."}
    ],
    max_tokens=1024,
    temperature=0.7
)
print(response.choices[0].message.content)
```

## 🛠 సమస్య పరిష్కారం (Troubleshooting)

- **చెల్లని API కీ**: [Numeric](https://www.numeric.tech) వద్ద మీ కీని సరిచూడండి.
- **మోడల్ కనుగొనబడలేదు**: `sutra-v2` ఉపయోగించండి. SUTRA-V1 మార్చి 22, 2025న నిలిపివేయబడింది.
- **రేట్ పరిమితులు**: అభ్యర్థనల ఫ్రీక్వెన్సీని తగ్గించండి లేదా  వద్ద Numericని సంప్రదించండి.
