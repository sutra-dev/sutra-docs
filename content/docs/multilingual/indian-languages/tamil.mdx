இந்த நோட்புக் **SUTRA-V2**-ஐப் பயன்படுத்தி **தமிழில்** பல மொழி AI பயன்பாடுகளை உருவாக்குவதற்கான வழிமுறைகளை விளக்குகிறது. Numeric-ஆல் உருவாக்கப்பட்ட SUTRA-V2, தமிழ் உட்பட 50+ மொழிகளை ஆதரிக்கிறது மற்றும் OpenAI இணக்கமான API மூலம் உரையாடல் மற்றும் வழிமுறை பணிகளை செயல்படுத்துகிறது.

## 🔧 முன்நிபந்தனைகள் (Prerequisites)

- [Numeric](https://www.numeric.tech) இலிருந்து SUTRA API விசையைப் பெறுங்கள்.
- API விசையை பாதுகாப்பாக சேமிக்கவும் (எ.கா. Google Colab ரகசியமாக அல்லது சூழல் மாறியாக).

## 📦 படி 1: சார்புகளை நிறுவுதல் (Install Dependencies)

```bash
!pip install -qU openai
```

## 🔐 படி 2: SUTRA கிளையன்டை துவக்குதல் (Initialize SUTRA Client)

```python
from openai import OpenAI

client = OpenAI(
    api_key="your-api-key-here",  # SUTRA API விசை
    base_url="https://api.numeric.tech/v1"  # SUTRA API முனைப்புள்ளி
)
```

## 💬 படி 3: தமிழில் உரையாடல் (Tamil Conversation)

```python
response = client.chat.completions.create(
    model="sutra-v2",
    messages=[
        {"role": "system", "content": "நீங்கள் ஒரு உதவிகரமான மற்றும் அறிவார்ந்த உதவியாளர்."},
        {"role": "user", "content": "வணக்கம்! தமிழ் இலக்கியத்தைப் பற்றி சொல்லுங்கள்."}
    ]
)

print(response.choices[0].message.content)
```

## 🌟 முக்கிய அம்சங்கள்

- தமிழில் இயல்பான உரையாடல்
- மேம்பட்ட சூழல் புரிதல்
- சிக்கலான கேள்விகளுக்கு பதிலளித்தல்
- கலாச்சார ரீதியாக பொருத்தமான பதில்கள்

## 📝 குறிப்புகள்

- பதில்களின் தரத்தை உறுதிப்படுத்த தெளிவான மற்றும் குறிப்பிட்ட prompt-களைப் பயன்படுத்தவும்.
- உணர்திறன் தகவல்களைக் கையாளும்போது கவனமாக இருக்கவும்.
- API வரம்புகளை கவனத்தில் கொள்ளவும்.
