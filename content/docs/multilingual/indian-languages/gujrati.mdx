આ નોટબુક **SUTRA-V2** નો **ગુજરાતી** માં ઉપયોગ કેવી રીતે કરવો તે બતાવે છે, જે બહુભાષી AI એપ્લિકેશન્સ બનાવવામાં મદદ કરે છે. Numeric દ્વારા વિકસિત, SUTRA-V2 ગુજરાતી સહિત 50 થી વધુ ભાષાઓને સપોર્ટ કરે છે.

## 🔧 આવશ્યક શરતો (Prerequisites)

- [Numeric](https://www.numeric.tech) પરથી SUTRA API કી મેળવો.
- API કીને સુરક્ષિત રીતે સંગ્રહો (ઉદાહરણ તરીકે, Google Colab માં ગુપ્ત કી તરીકે).

## 📦 પગલું 1: નિર્ભરતાઓ સ્થાપિત કરો (Install Dependencies)

```bash
!pip install -qU openai
```

## 🔐 પગલું 2: SUTRA ક્લાયન્ટ શરૂ કરો (Initialize SUTRA Client)

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_SUTRA_API_KEY",
    base_url="https://api.two.ai/v2"
)
```

## 💬 પગલું 3: મૂળભૂત ચેટ પૂર્ણતા (Basic Chat Completion)

```python
response = client.chat.completions.create(
    model="sutra-v2",
    messages=[
        {"role": "system", "content": "તમે એક મદદરૂપ AI છો જે સંક્ષિપ્તમાં જવાબ આપે છે."},
        {"role": "user", "content": "કૃત્રિમ બુદ્ધિ શું છે? ત્રણ વાક્યોમાં સમજાવો."}
    ],
    max_tokens=1024,
    temperature=0.7
)
print(response.choices[0].message.content)
```

## 🛠 સમસ્યા નિવારણ (Troubleshooting)

- **અમાન્ય API કી**: [Numeric](https://www.numeric.tech) પર તમારી કી ચકાસો.
- **મોડેલ મળ્યું નથી**: `sutra-v2` નો ઉપયોગ કરો. SUTRA-V1 22 માર્ચ 2025 ના રોજ બંધ થયું હતું.
- **દર મર્યાદા**: વિનંતીની આવૃત્તિ ઘટાડો અથવા  પર Numeric નો સંપર્ક કરો.
