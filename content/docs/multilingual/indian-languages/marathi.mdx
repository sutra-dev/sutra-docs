हे नोटबुक **SUTRA-V2** चा **मराठी** मध्ये वापर कसा करायचा हे दाखवते, ज्यामुळे बहुभाषिक AI अनुप्रयोग तयार होऊ शकतात. TWO AI द्वारे विकसित, SUTRA-V2 50 पेक्षा जास्त भाषांना समर्थन देते, ज्यात मराठीचा समावेश आहे.

## 🔧 पूर्वअट (Prerequisites)

- [http://platform.two.ai](http://platform.two.ai) वरून SUTRA API की मिळवा.
- API की सुरक्षितपणे साठवा (उदाहरणार्थ, Google Colab मध्ये गुप्त की म्हणून).

## 🔐 चरण 2: SUTRA क्लायंट प्रारंभ करा (Initialize SUTRA Client)

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_SUTRA_API_KEY",
    base_url="https://api.two.ai/v2"
)
```

## 💬 चरण 3: मूलभूत चॅट पूर्णता (Basic Chat Completion)

```python
response = client.chat.completions.create(
    model="sutra-v2",
    messages=[
        {"role": "system", "content": "तुम्ही एक सहाय्यक AI आहात जो संक्षिप्तपणे उत्तर देतो."},
        {"role": "user", "content": "कृत्रिम बुद्धिमत्ता म्हणजे काय? तीन वाक्यांत समजावून सांगा."}
    ],
    max_tokens=1024,
    temperature=0.7
)
print(response.choices[0].message.content)
```
