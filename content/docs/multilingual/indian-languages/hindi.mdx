This notebook demonstrates how to use **SUTRA-V2** in **Hindi** to create multilingual AI applications. SUTRA-V2, developed by TWO AI, supports over 50 languages, including Hindi, for chat and instruction tasks via an OpenAI-compatible API.

## 🔧 आवश्यकताएँ (Prerequisites)

- [http://platform.two.ai](http://platform.two.ai) से SUTRA API कुंजी प्राप्त करें।
- API कुंजी को सुरक्षित रूप से संग्रहित करें (उदाहरण के लिए, Google Colab में गुप्त कुंजी के रूप में)।

## 🔐 चरण 2: SUTRA क्लाइंट प्रारंभ करें (Initialize SUTRA Client)

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_SUTRA_API_KEY",
    base_url="https://api.two.ai/v2"
)
```

## 💬 चरण 3: मूल चैट पूर्णता (Basic Chat Completion)

```python
response = client.chat.completions.create(
    model="sutra-v2",
    messages=[
        {"role": "system", "content": "आप एक सहायक AI हैं जो संक्षेप में उत्तर देता है।"},
        {"role": "user", "content": "आर्टिफिशियल इंटेलिजेंस क्या है? तीन वाक्यों में समझाएं।"}
    ],
    max_tokens=1024,
    temperature=0.7
)
print(response.choices[0].message.content)
```
