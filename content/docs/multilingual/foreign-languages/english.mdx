This notebook demonstrates how to use **SUTRA-V2** in **English** to create multilingual AI applications. SUTRA-V2, developed by Numeric, supports over 50 languages, including English, for chat and instruction tasks via an OpenAI-compatible API.

## 🔧 Prerequisites

- Contact [Numeric](https://www.numeric.tech) for enterprise API access.
- Store the API key securely (e.g., in Google Colab secrets or environment variables).

## 📦 Step 1: Install Dependencies

## 🔐 Step 2: Initialize SUTRA Client

```python
from openai import OpenAI

client = OpenAI(
    api_key="YOUR_SUTRA_API_KEY",
    base_url="https://api.numeric.tech/v2"
)
```

## 💬 Step 3: Basic Chat Completion

```python
response = client.chat.completions.create(
    model="sutra-v2",
    messages=[
        {"role": "system", "content": "You are a helpful AI that answers concisely."},
        {"role": "user", "content": "What is artificial intelligence? Explain in three sentences."}
    ],
    max_tokens=1024,
    temperature=0.7
)
print(response.choices[0].message.content)
```

## 🛠 Troubleshooting

- **Invalid API Key**: Contact [Numeric](https://www.numeric.tech) for API support.
- **Model Not Found**: Use `sutra-v2`. SUTRA-V1 was deprecated on March 22, 2025.
- **Rate Limits**: Reduce request frequency or contact Numeric support.
